# swagger-documentation
Documentation of the services.
If this repository is not up to date, or you feel that it is missing something, you can check more details on each service.

You need to run all services via docker-compose and then access the up to date swagger documentation file, using the example below:

 - Authentication Service: http://localhost:8081/v3/api-docs
 - Company Service: http://localhost:8082/v3/api-docs
 - Customer Service: http://localhost:8083/v3/api-docs
 - Finance Service: http://localhost:8085/v3/api-docs

Then you can copy the JSON and follow the steps below.

# How to open the documentation.

 - Access the URL https://editor-next.swagger.io/
 - Copy either the open-api (yaml or json) file content and paste it in this web site. You can check here all the documentation of the endpoints, all you need to send for each request and the expected responses.
